## 1. Основні можливості

- **Каталог і розклад слотів:** фільтрація аудиторій за місткістю, корпусом і оснащенням; перегляд денної сітки та тижневого календаря `7 × 6` (42 академічні слоти у часовому поясі `Europe/Kyiv`).
- **Атомарне бронювання:** створення заявок (`PENDING`), захист від конкурентного подвійного запису через транзакції `BEGIN IMMEDIATE` і частковий унікальний індекс `idx_bookings_active_slot`.
- **Пошук альтернатив:** автоматичний ранжований підбір найближчих вільних слотів за індексом відповідності `S` та бронювання альтернативи в 1 клік.
- **Панель диспетчера:** погодження (`CONFIRMED`) та вмотивоване відхилення (`REJECTED`) заявок, закриття/відкриття аудиторій із перевіркою активних бронювань, журнал аудиту подій.
- **Безпека:** сесії `HttpOnly` + `SameSite=Lax`, підписані токени `X-CSRF-Token` (`HMAC-SHA256`), перевірка `Origin`, хешування паролів `scrypt`, обмеження спроб входу (`HTTP 429`), заголовки `CSP`, `X-Frame-Options`, `X-Content-Type-Options`.

---

## 2. Технологічний стек

- **Backend:** Python 3.10–3.12, FastAPI, Uvicorn, Pydantic v2, `zoneinfo` (`tzdata`).
- **База даних:** SQLite 3 (`WAL`, `PRAGMA foreign_keys = ON`, версіоновані SQL-міграції).
- **Frontend:** HTML5, адаптивний CSS3 (`360px` / `768px` / `1440px`, WCAG 2.2 AA), чистий JavaScript (ES2022).
- **Тестування:** `pytest`, `coverage`, `httpx`.

## 3. Швидкий запуск

### Варіант А (Windows — в один клік)

```cmd
run.bat
```

Для повного прогону автотестів і перевірок:

```cmd
test.bat
```

### Варіант Б (покроковий запуск із чистого середовища)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
Copy-Item .env.example .env
python seed/seed_data.py
python -m uvicorn src.main:app --host 127.0.0.1 --port 8000 --reload
```

Адреси після запуску:
- Вебінтерфейс: http://127.0.0.1:8000/
- Документація OpenAPI (Swagger UI): http://127.0.0.1:8000/docs
- Стан системи: http://127.0.0.1:8000/api/health

## 6. Структура репозиторію

```text
├── migrations/                  # SQL-міграції схеми БД (001, 002)
├── seed/                        # Ідемпотентне наповнення початковими даними
├── src/
│   ├── controllers/             # Маршрути REST API (FastAPI)
│   ├── domain/                  # Доменні моделі та бізнес-правила
│   ├── repositories/            # Репозиторії доступу до SQLite 3
│   ├── schemas/                 # Схеми DTO та валідація запитів/відповідей
│   ├── services/                # Сервіси бронювання, альтернатив і автентифікації
│   ├── static/                  # Таблиці стилів CSS3 та клієнтська логіка JS
│   ├── templates/               # Головний HTML5-шаблон
│   ├── config.py                # Конфігурація середовища (.env, Europe/Kyiv)
│   ├── database.py              # Підключення SQLite WAL і менеджер міграцій
│   └── main.py                  # Точка входу FastAPI та захисне middleware
├── scripts/                     # Автономні скрипти перевірки запуску і якості
├── tests/                       # Модульні, інтеграційні, конкурентні й безпекові тести
├── .env.example                 # Шаблон змінних середовища
├── requirements.txt             # Залежності Python
├── run.bat                      # Скрипт запуску сервера (Windows)
└── test.bat                     # Скрипт запуску комплексу перевірок (Windows)
```
